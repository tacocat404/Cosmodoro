# Open, real-world data assets for a calm, photoreal solar-system and sky scene in a web app (licenses, attribution, sandbox-verified URLs)

How this was verified (2026-10-29, Cosmodoro sandbox): every URL marked "200" below was checked with `curl -s -o /dev/null -I -w '%{http_code}' <url>` (real HTTP status) and `curl -sI` (Content-Length). Image dimensions were read from the file header with a ranged GET of the first 256 KB, or from files extracted from npm tarballs (extracted into `/tmp/claude-0/asset-check/` and deleted right after). "MB" means MiB (2^20 bytes). Pitfall: through the sandbox proxy, the first status line `curl -sI` prints is the proxy's `HTTP/1.1 200 Connection established`, so a missing raw.githubusercontent.com file looks like "200" unless you read `%{http_code}`. Missing raw files return a 14-byte body, `404: Not Found`.

Hosts reachable from the sandbox: raw.githubusercontent.com, registry.npmjs.org, gitlab.com, pypi.org. Hosts blocked from the sandbox: github.com HTML, api.github.com, unpkg, jsDelivr, solarsystemscope.com, nasa.gov, eso.org, usgs.gov, wikimedia, codeberg. Because the primary publisher pages were unreachable, license statements come from (a) license or credit files inside the hosting repos and packages, read directly, and (b) web-search summaries of the primary pages, both cited inline.

## 1. Planet and moon texture maps: best sources, exact licenses, verified copies

### Takeaway
The most practical, clearly licensed set is the **Solar System Scope (SSS) texture set (CC BY 4.0)**, verified here through three hosts: **pyvista/data** (2k set with an explicit CC BY 4.0 README), **fury-gl/fury-data** (8k), and **three.js** (4k Earth day/night/packed maps, credited to SSS in the example source). The **public-domain** alternatives come from DLR's CosmoScout VR (NASA/USGS/JPL maps for Ceres, Vesta, Io, Titan, Enceladus, Pluto, Triton) and the npm packages `astraeus` / `astraeus-data` (NASA Blue Marble NG, CGI Moon Kit, USGS Galilean moons, Magellan Venus). These public-domain maps need no license, only courtesy or required credit. The older three.js Earth textures, Planet Pixel Emporium, Björn Jónsson and Steve Albers maps have unverified or restrictive terms (see section 6).

#### Supporting facts
- pyvista/data accepts only datasets with a clear, permissive, commercial-use-compatible license, and requires a license file next to each dataset — [pyvista/data README](https://raw.githubusercontent.com/pyvista/data/master/README.md). PyVista's loaders say each planet texture was "obtained from Solar Textures (solarsystemscope.com/textures)" — [pyvista planets.py](https://raw.githubusercontent.com/pyvista/pyvista/main/pyvista/examples/planets.py).
- FURY downloads its planet textures (`8k_mercury`, `8k_venus_surface`, `8k_mars`, `8k_saturn`, `8k_saturn_ring_alpha.png`, `2k_uranus`, `2k_neptune`, `8k_sun`, `1_earth_8k`, `2_no_clouds_8k`, `5_night_8k`, `1_earth_16k`) from `raw.githubusercontent.com/fury-gl/fury-data/master/textures/` — [fury fetcher.py](https://raw.githubusercontent.com/fury-gl/fury/master/fury/data/fetcher.py).

### Inferences
- **Byte-identical SSS 2k copies confirm provenance.** The SSS 2k files are byte-identical across independent hosts:
  - Uranus 77,751 B and Neptune 241,580 B: pyvista = CosmoScout = astraeus = fury.
  - Mercury 872,555 B: pyvista = CosmoScout = astraeus.
  - Sun 822,427 B and Jupiter 498,976 B: pyvista = astraeus.
  - Moon 1,053,869 B, Saturn 199,916 B and Venus atmosphere 229,696 B: pyvista = CosmoScout.

  So these are the unmodified SSS originals. pyvista/data is the most trustworthy host because it has an explicit license README and a license policy.
- **SSS "8k" gas giants and Sun are really 4k.** SSS's "8k" Jupiter, Saturn and Sun files measured 4096×2048 in every copy checked. Treat them as 4k. Real 8k exists only for Mercury, Venus surface, Mars, Moon and Earth.
- **Recommended web starter kit (2k–4k, minimal attribution burden):**
  - SSS 2k for Mercury, Mars, Jupiter, Saturn, Uranus, Neptune and the Sun, plus SSS 4k Venus clouds.
  - three.js SSS-derived 4k Earth day + night + packed R/G/B map, which gives bump, ocean roughness/specular and clouds in one texture.
  - NASA LRO Moon (astraeus) or SSS 2k Moon.
  - USGS/NASA public-domain maps for Ceres, Io, Europa and Titan.
  - One attribution line covers everything: "Planet textures: Solar System Scope (CC BY 4.0); NASA/JPL, USGS Astrogeology, NASA SVS (public domain)".
- **Zero-attribution Earth.** For an Earth set with no attribution obligation, combine Natural Earth III (no-clouds day + night, public domain) with NASA BMNG. The turban/webgl-earth clouds, water and bump files are probably NE III too, but that provenance is undocumented.
- **Vendor the files.** Copy the files into the app with a CREDITS file rather than hotlinking raw.githubusercontent.com: branches can change and raw GitHub is not a CDN. If you do reference raw URLs, pin them to a commit SHA.

### Gaps
- solarsystemscope.com was blocked for both curl and WebFetch. The SSS license (CC BY 4.0) is therefore confirmed only via mirrors' license files, Qt's attribution page and Meta's credits. SSS's native resolutions and exact file list were not checked at the source.
- No sandbox-reachable copy was found of SSS `2k/8k_earth_normal_map.tif`, `2k/8k_earth_specular_map.tif`, `8k_earth_nightmap.jpg` or `8k_earth_clouds.jpg` (probes of mwilmsm/Planets and TU-Dublin Solar-XR returned 404). The three.js packed map stands in for these.
- USGS Astrogeology's generic rights statement and the Planetary Society Jupiter map license were not retrieved at source. Those licenses rely on the CosmoScout and astraeus records.
- No openly licensed, higher-detail real Uranus/Neptune maps were found beyond SSS 2k. Björn Jónsson's and Steve Albers' maps have unverified terms (section 6).
- The provenance of three.js's legacy textures (`earth_atmos_2048`, `earth_normal_2048`, `earth_specular_2048`, `earth_lights_2048`, `earth_clouds_1024`, `moon_1024`) and of three-globe's images could not be established.
- astraeus / astraeus-data are new single-maintainer 2026 packages. Their licence records are detailed but second-hand.

### Inferences
- Ring radii in Saturn radii (computed from the NSSDC values above): D-ring inner edge 1.110, C-ring inner edge 1.239, Cassini Division 1.950–2.030, A-ring outer edge 2.270. A common approach is a flat ring mesh from about 1.11–1.24 R_S to 2.27 R_S with the strip's u coordinate running radially. Calibrate by lining up the dark Cassini Division in the strip with 1.95–2.03 R_S.
- For a calm scene, the 8k strip (65 KB) costs almost nothing in bandwidth. Downsample it on the GPU with mipmaps and anisotropic filtering rather than shipping the 2k strip.

### Gaps
- SSS does not document which radii the strip's first and last pixels represent (not verifiable; site blocked).
- I found no openly licensed **lit-side / unlit-side / forward-scattering** ring textures. Björn Jónsson's multi-view ring profiles exist, but their terms are unclear. Raw Cassini radial-profile data in the PDS (public domain) would require processing and was not evaluated.

- Convert d3-celestial longitudes back to RA with `ra_deg = lon < 0 ? lon + 360 : lon`. HYG `ra` is in **hours**.

ESA publishes equirectangular versions of both — [ESA 60196 equirectangular](https://sci.esa.int/web/gaia/-/60196-gaia-s-sky-in-colour-equirectangular-projection), [EDR3 equirectangular](https://sci.esa.int/web/gaia/-/the-colour-of-the-sky-from-gaia-s-early-data-release-3-equirectangular-projection).
- Kevinmloch's Commons file: 8,000×4,000 px, uploaded 10 Feb 2021, foreground stars within 3 kpc removed, with the caveat that parallax uncertainty affects that cut — [Commons (mirror)](https://commons.wikipedia.com/wiki/File:Milky_Way_360-degree_rendering_with_foreground_stars_removed.png); licence per [astraeus-data NOTICE](https://registry.npmjs.org/astraeus-data/-/astraeus-data-0.3.0.tgz).
- Axel Mellinger's all-sky panorama is "Credit & Copyright: Axel Mellinger" ([APOD](https://apod.nasa.gov/apod/ap091125.html)) and "all rights reserved" per a third-party page ([Randolph College](https://faculty.randolphcollege.edu/tmichalik/mlkyway.htm)). Prior uses were by case-by-case permission.
- Frame check (my measurement, method in Inferences): the band's peak brightness sits within a few degrees of the image equator in the SSS 8k (mean |peak latitude| 7.5°), ESO copies (1.7–1.8°), SVS Tycho (4.2°) and Kevinmloch (3.4°) files. three-globe's `night-sky.png` (4096×2048, 0.86 MB, [tarball](https://registry.npmjs.org/three-globe/-/three-globe-2.45.6.tgz)) showed no Milky Way band and its provenance is undocumented.

### Inferences
- **Calmest, most "photoreal-but-quiet" option:** a dim Milky Way layer without bright stars (Kevinmloch Gaia render on npm now, or SVS `milkyway_2020_4k` if you can fetch it outside the sandbox) plus catalog stars drawn as points (section 3). Baked-star panoramas at 4k (0.0879°/px per the [black-hole-lab summary of SVS 4851](https://raw.githubusercontent.com/steveking-gh/black-hole-lab/master/sky/maps/README.md)) render stars as soft blobs and double-count bright stars when combined with a catalog.
- **If one image must do everything:** the SSS 8k (CC BY 4.0, 1.8 MB) or ESO 4k (CC BY 4.0, natural photographic color) are the simplest. Both need only a credit line. The ESO credit text must be exactly "ESO/S. Brunier".
- **Orientation:** these images are galactic. To align with an equatorial scene, rotate the sky sphere using the galactic pole (RA 192.859°, Dec +27.128°) and galactic centre (RA 266.405°, Dec −28.936°), as implemented in astraeus `src/assets/sky.js` ([npm](https://registry.npmjs.org/astraeus/-/astraeus-0.3.0.tgz)). spacekit applies a galactic-to-ecliptic transform with a 180° longitude offset for its NASA map ([Skybox.ts](https://raw.githubusercontent.com/typpo/spacekit/master/src/Skybox.ts)).
- **ShareAlike:** CC BY-SA images (Gaia/ESA, Kevinmloch) are fine commercially, but any modified version of the image must stay CC BY-SA. Keep it as a separate, unmodified asset file.

### Gaps
- The SVS 4851 originals (EXR/TIFF, including the star-free `milkyway_2020` product and the celestial-frame versions) were not reachable from the sandbox, and no GitHub copy was found (code search returned only documentation files).
- No sandbox-reachable copy of the ESA Gaia equirectangular sky maps was found.
- SSS does not document the frame or source of `8k_stars_milky_way`. "Galactic-like" is my brightness test, not a published statement.
- The frame test is heuristic: 256×128 downsample, Gaussian blur, per-column brightness peak.

## 5. Sandbox-reachable hosting and verification

### Takeaway

## 6. Assets with unclear, non-commercial or restrictive licenses (avoid or clear first)

### Takeaway
Avoid hosting the following in a public web app unless permission is obtained:
- Planet Pixel Emporium maps (no redistribution "as is").
- Björn Jónsson maps and ring profiles (terms unverified, conflicting reports).
- Steve Albers maps (conflicting, dated terms).
- Axel Mellinger's panorama (copyrighted).
- The legacy three.js Earth/Moon textures and three-globe images (undocumented provenance).

Also note: SSS "fictional" dwarf-planet maps are not real data; HYG and Gaia-derived images carry ShareAlike.

### Cited Findings
- **Planet Pixel Emporium (James Hastings-Trew).** Maps may be used as source material for renderings, including commercial ones. However, a search summary of the site's terms says the maps "can't be redistributed as-is, though results made with them can be shared". Its Uranus texture is fictional — [PPE planets page](https://planetpixelemporium.com/planets.html), [search summary context](https://planetside.co.uk/forums/index.php?msg=82348). PPE's Saturn ring map was built from Björn Jónsson's ring map — [PPE Saturn](https://planetpixelemporium.com/saturn.html). A web app serving the files to browsers is redistribution.
- **Björn Jónsson.** A Celestia forum repost quotes his site: use needs no special permission, but credit "created by Björn Jónsson". The FlatPlanet catalogue marks his Saturn map "non-redistributable". These conflict, and his site (bjj.mmedia.is) could not be reached — [Celestia forum](https://celestiaproject.space/forum/viewtopic.php?p=27533), [FlatPlanet catalogue](https://flatplanet.sourceforge.net/maps/alien.html).
- **Steve Albers.** A forum post quotes his old site as allowing any use with credit in commercial works, but also cites a GNU license. Dated and conflicting — [Planetside forum](https://planetside.co.uk/forums/index.php?msg=82348).
- **Axel Mellinger panorama.** Copyrighted; prior uses were by permission — [APOD](https://apod.nasa.gov/apod/ap091125.html), [Randolph College page](https://faculty.randolphcollege.edu/tmichalik/mlkyway.htm), [EurekAlert listing](https://www.eurekalert.org/multimedia/739517).
- **three.js legacy textures** (`earth_atmos_2048`, `earth_normal_2048`, `earth_specular_2048`, `earth_lights_2048`, `earth_clouds_1024`, `moon_1024`). No source or license found; three.js credits only its newer 4k Earth files to SSS — [webgpu_tsl_earth.html](https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/webgpu_tsl_earth.html).
- **three-globe images** (`earth-blue-marble`, `earth-night`, `earth-topology`, `earth-water`, `night-sky`). The package README gives no image credits, except that clouds.png comes "from turban/webgl-earth", which itself has no license or credits file — [three-globe tarball](https://registry.npmjs.org/three-globe/-/three-globe-2.45.6.tgz), [turban/webgl-earth README](https://raw.githubusercontent.com/turban/webgl-earth/master/README.md).
- **CosmoScout's Europa/Callisto** (John van Vliet, Celestia Motherlode) are marked only "CC", variant unspecified. **CosmoScout's Jupiter** ("CC-BY", Planetary Society) has no confirmed licensor or credit line — [CosmoScout credits](https://raw.githubusercontent.com/cosmoscout/cosmoscout-vr/main/plugins/csp-simple-bodies/textures/planet-texture-credits.md).
- **ShareAlike assets** (allowed commercially, but derivatives must stay SA): HYG v4.x CC BY-SA 4.0 ([LICENSE](https://raw.githubusercontent.com/astronexus/HYG-Database/main/LICENSE)), ESA Gaia images CC BY-SA 3.0 IGO ([ESA](https://sci.esa.int/web/gaia/-/60196-gaia-s-sky-in-colour-equirectangular-projection)), Kevinmloch Gaia render CC BY-SA 4.0 ([astraeus-data NOTICE](https://registry.npmjs.org/astraeus-data/-/astraeus-data-0.3.0.tgz)).

### Inferences
- The SSS files `4k_ceres_fictional`, `4k_eris_fictional`, `4k_haumea_fictional` and `4k_makemake_fictional` are labeled fictional by their own file names. Do not use them where realism matters. Use the CosmoScout/USGS Dawn Ceres map instead.
- If the app's own source or assets must remain non-SA, prefer d3-celestial (BSD-3) over HYG for stars. Prefer SSS, ESO or NASA over Gaia-derived images for the sky.

### Gaps
- None of the restrictive or unclear terms above could be checked on the rights holders' own pages (sites blocked or not found). Treat them as unresolved rather than prohibited, and contact the authors if those assets are wanted.
