# 우주뽀모도로(Cosmodoro) 개발 계획

메인은 웹 서비스, 확장은 PC 앱과 안드로이드 앱이에요. DB는 Supabase 없이 직접 운영하고, 로그인과 캘린더 일정을 넣어요. 나중에 멀티 기능(함께 비행)을 붙일 수 있게 처음부터 구조를 잡아요.

## 1. 전체 구조

```
cosmodoro/
  apps/web        웹 (지금 v5 메인·비행 페이지를 옮겨 와요) — Vite
  apps/native     PC·안드로이드 앱 껍데기 — Tauri 2 (웹 빌드를 그대로 감싸요)
  server          API 서버 — Node.js + Hono
                  DB: PostgreSQL + Drizzle ORM (테이블을 코드로 관리)
                  로그인: Better Auth (직접 운영하는 DB에 붙는 오픈소스 인증 라이브러리)
  packages/shared 웹·앱·서버가 같이 쓰는 타입, API 클라이언트, 동기화 로직
```

- **웹이 본체:** 앱은 같은 웹 코드를 감싸기만 해서 화면을 두 번 만들지 않아요.
- **DB 직접 운영:** 개발할 땐 설치 없이 도는 PGlite(파일형 PostgreSQL)를 쓰고, 배포할 땐 진짜 PostgreSQL을 써요. 코드는 같아요.
- **로그인:** 비밀번호 해시·세션·구글 로그인 같은 보안 부분은 Better Auth에 맡겨요. 데이터는 전부 우리 DB에 저장돼요.
- **오프라인 우선:** 기록은 먼저 기기(IndexedDB)에 저장하고, 로그인돼 있으면 서버로 올려요. 비행 중에 인터넷이 끊겨도 문제없어요. 로그인 전에 쌓은 기록은 첫 로그인 때 계정으로 합쳐요.

## 2. DB 테이블 (처음 버전)

| 테이블 | 내용 |
|---|---|
| users, sessions, accounts | 로그인 (Better Auth가 관리) |
| flights | 비행 기록: 주제, 분, 시작·끝 시각, 미션, 완료 여부, 평점 |
| missions | 할 일: 제목, 주제, 완료, 순서 |
| settings | 하루 목표, 기본 비행 시간, 지나가는 우주선 표시 등 |
| calendar_events | 일정: 제목, 시작·끝, 주제, 연결된 미션, 알림, 반복 |
| (나중) rooms, room_members | 멀티: 함께 비행하는 방 |

모든 행에 `user_id`, `updated_at`을 둬서 기기 사이 동기화와 멀티 기능을 같은 방식으로 처리해요.

## 3. 캘린더

1. **앱 안 캘린더:** "일정" 탭을 새로 만들어요. 날짜를 골라 "화성 · 코딩 · 50분 · 미션"처럼 비행 일정을 넣어요. 그 시간이 되면 알림이 오고, 누르면 바로 탑승권이 열려요.
2. **외부 캘린더 구독:** 내 일정을 iCal(.ics) 주소로 내보내서 구글·애플·아웃룩 캘린더에서 구독할 수 있게 해요. 구글 승인 절차가 필요 없어요.
3. **(나중) 구글 캘린더 양방향 연동:** 구글 OAuth 심사가 필요해서 뒤로 미뤄요.

## 4. 멀티 기능 (나중)

- **함께 비행:** 같은 방에 들어온 사람들이 같은 타이머로 출발하고, 서로의 우주선이 옆에서 같이 날아요.
- 서버에 WebSocket을 열어 방 상태를 주고받아요. 지금부터 API와 DB를 사용자 기준으로 짜 두면, 나중에 방(rooms) 테이블과 실시간 연결만 더하면 돼요.

## 5. 진행 순서

| 단계 | 할 일 | 결과 |
|---|---|---|
| 0 | git 저장소, 폴더 구조, v5 페이지를 Vite 웹 앱으로 옮기기 (화면 변화 없음) | `npm run dev`로 지금과 똑같이 실행 |
| 1 | 기기 저장소(IndexedDB) 정리, 통계를 예시 데이터 대신 실제 비행 기록으로 계산 | 진짜 통계·별자리 |
| 2 | 서버 + DB + 로그인 (이메일·비밀번호 먼저, 구글은 다음) | 로컬에서 회원가입·로그인 |
| 3 | 동기화와 로그인 화면 (오른쪽 위 "로그인") | 캐시를 지워도 기록 유지 |
| 4 | 일정 탭, 알림, iCal 구독 주소 | 캘린더 기능 |
| 5 | 배포 (웹: 정적 호스팅, 서버+DB: Fly.io·Railway 같은 곳 또는 VPS) | 링크로 접속 |
| 6 | PC 앱, 안드로이드 앱 (Tauri 2), 로컬 알림 | 설치형 앱 |
| 7 | 멀티: 방, 실시간 함께 비행 | 같이 공부하기 |

각 단계는 브라우저에서 직접 확인한 뒤 다음으로 넘어가요. 지금 drafts 폴더는 그대로 둬서 언제든 시안으로 돌아갈 수 있어요.
